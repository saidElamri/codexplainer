# 🔍 Code Explainer with Gemini AI

This project is a simple **Flask web app** that uses **Google Gemini** to explain Python code step by step.  
It supports explanations for **beginners** and **advanced users**, and converts AI responses into **formatted HTML with Markdown**.

---

## 🚀 Features
- Paste Python code and get AI-generated explanations
- Beginner and advanced explanation modes
- Markdown support (syntax highlighting, tables, code blocks)
- `.env` support for storing API keys securely
- Flask web interface
